# Instituto Fiel ao Futuro - Plataforma Web

> **⚠️ Nota:** Este é um projeto acadêmico. O "Instituto Fiel ao Futuro" é uma ONG fictícia criada exclusivamente para fins educacionais.

Plataforma web desenvolvida como projeto prático para o curso de Análise e Desenvolvimento de Sistemas da Universidade Positivo. O repositório contém uma *Single Page Application* (SPA) construída puramente com JavaScript (Vanilla JS), com o objetivo de simular a interface de uma instituição real para apresentar projetos sociais e captar voluntários de forma acessível.

## 🚀 Tecnologias Utilizadas

* HTML5 e CSS3
* JavaScript Puro (ES6 Modules)
* Git e GitHub (Versionamento via GitFlow)

## ✨ Principais Funcionalidades

* **Navegação fluida (SPA):** Troca de páginas (Início, Projetos, Cadastro) sem recarregar o navegador.
* **Validação em tempo real:** Máscara de telefone automática e verificação de dados no formulário.
* **Modais com CSS:** Janela de confirmação construída de forma leve usando apenas o seletor CSS `:target`.
* **Armazenamento:** Salva os dados do voluntário diretamente no `localStorage` do navegador.
